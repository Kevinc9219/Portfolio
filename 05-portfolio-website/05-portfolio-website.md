# 🌐 Persoonlijke Portfolio Website

Mijn persoonlijke portfolio website gebouwd met HTML, CSS en JavaScript. Volledig responsive design, gehost via GitHub Pages.

🔗 **Live bekijken:** [kevincallaert.github.io](https://kevincallaert.github.io/05-portfolio-website)

---

## 🚀 Secties

- 👋 **Hero** — introductie en tagline
- 👤 **Over mij** — achtergrond en verhaal
- 🛠️ **Skills** — technische en soft skills met iconen
- 💼 **Projecten** — showcase van GitHub projecten
- 📬 **Contact** — contactformulier en links

---

## 🛠️ Technologieën

| Tool | Gebruik |
|------|---------|
| HTML5 | Structuur |
| CSS3 | Styling, animaties, responsive |
| JavaScript | Interactiviteit, scroll-effecten |
| GitHub Pages | Hosting (gratis!) |

---

## ▶️ Lokaal bekijken

```bash
# 1. Repository klonen
git clone https://github.com/kevincallaert/05-portfolio-website.git

# 2. Open index.html in je browser
# Geen server nodig — pure HTML/CSS/JS
```

---

## 🚀 Deployen naar GitHub Pages

```
1. Ga naar je GitHub repository
2. Settings → Pages
3. Source: main branch / root
4. Opgeslagen → live op kevincallaert.github.io/05-portfolio-website
```
