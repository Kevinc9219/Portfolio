# 🧮 Rekenmachine – WinForms

Een grafische rekenmachine gebouwd met C# en Windows Forms. Ondersteunt basisbewerkingen en houdt een geschiedenis bij van alle berekeningen.

---

## 🚀 Features

- ➕ Optelling, aftrekking, vermenigvuldiging, deling
- 📜 Geschiedenis van de laatste 10 berekeningen
- ⌨️ Ondersteuning voor toetsenbordinvoer
- 🔄 Clear & backspace functionaliteit
- ⚠️ Foutafhandeling (bijv. deling door nul)

---

## 🛠️ Technologieën

| Tool | Versie |
|------|--------|
| C# | 10+ |
| .NET | 6.0+ |
| Windows Forms | - |

## ▶️ Installatie & Gebruik

```bash
# 1. Repository klonen
git clone https://github.com/kevincallaert/02-rekenmachine-winforms.git

# 2. Open het .sln bestand in Visual Studio

# 3. Start met F5 of via Debug > Start Debugging
```

> ⚠️ Vereist Windows + Visual Studio 2022 of later
